# ✊🖐️✌️ Rock Paper Scissors

Project developed as part of **The Odin Project – Foundations**, focused on building an interactive **Rock Paper Scissors** game using **HTML**, **CSS**, and **Vanilla JavaScript**.

This project revisits the original console-based version and upgrades it to a fully interactive browser game with DOM manipulation and user interaction.

---

## 🚀 Live Demo

🔗 **[https://jormaedes.github.io/Rock-Paper-Scissors/](https://jormaedes.github.io/Rock-Paper-Scissors/)**

---

## 🎯 Project Goals

* Create a browser-based Rock Paper Scissors game
* Handle user input through UI buttons
* Implement game logic and score tracking
* Update the interface dynamically using JavaScript

---

## 🧠 Concepts Practiced

* DOM selection and manipulation
* Event listeners and user interaction
* JavaScript functions and control flow
* Random value generation with `Math.random()`
* Game state and score management

---

## 🛠️ Technologies Used

* **HTML5** – page structure
* **CSS3** – layout and styling
* **Vanilla JavaScript** – game logic and interactivity

---

## 📋 Features

* Buttons for Rock, Paper, and Scissors
* Random computer choice
* Score tracking for player and computer
* Display of round results (win / lose / draw)
* Option to restart the game

## ▶️ How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/jormaedes/Rock-Paper-Scissors.git
```

2. Navigate to the project folder:

```bash
cd rock-paper-scissors
```

3. Open `index.html` in your browser
